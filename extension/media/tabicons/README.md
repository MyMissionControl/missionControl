# Tab icons

One 16x16-ish line icon per webview panel, so a Mission Control tab is still
identifiable when the tab bar is crowded and the label is clipped (VS Code shrinks
a tab to 80px with `workbench.editor.tabSizing: shrink`, and clips the last tab at
the scroll edge even with the default `fit`).

VS Code does **not** recolor an `iconPath` SVG — it draws it as an image — so every
icon ships twice: `dark/` (#C5C5C5, for dark themes) and `light/` (#424242).

Generated by `scripts/gen-tabicons.mjs`; the mapping viewType → file lives in
`src/webview/tabIconModel.ts` and is covered by `tabIcon.test.ts`, which fails if a
new panel is added without an icon or an icon file goes missing.
